# SRCW: Split-Screen Rival Duel

Rival Duel for two players on one screen in Sonic Racing CrossWorlds.

### Install:

1. Download [UE4SS experimental-latest](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest).
2. Extract the `ue4ss` folder and `dwmapi.dll` into `SonicRacingCrossWorlds\UNION\Binaries\Win64`.
3. Extract the `SplitScreenRivalDuel` mod folder into `ue4ss\Mods`.
